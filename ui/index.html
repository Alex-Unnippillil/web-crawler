A LITTLE GUIDANCE

Make the most of your crawl

1. Start small

Use Quick look for a first run, or Try a local demo to crawl a tiny real site running on your computer. The demo deliberately includes a broken link and missing metadata.

2. Read the boundaries

The URL budget includes failed candidates. The progress bar shows budget used, not percent of the whole website discovered. Depth is discovery depth. External page links are counted, not crawled. Chromium may load public cross-origin resources through the guarded transport.

3. Review, then export

Click any page to inspect its metadata, links, and images. Issues include fetch failures and simple content checks—not a complete SEO or accessibility audit.

Pause, stop & save

Pause prevents new requests; in-flight requests finish. The run deadline continues while paused. Stop saves partial results. Closing the browser does not stop the server; press Ctrl+C in its terminal to quit.

Local & private

No account, analytics telemetry or cloud storage. Website JavaScript runs only in isolated Chromium, never in the Studio interface. Public sites still receive your requests and IP address. Private network targets are blocked in the GUI. Up to 30 runs are saved; delete old runs from History.

Visual Atlas

Use Link map for a spiderweb, radial map or discovery layers. Select a node to focus its neighborhood or trace a captured route from the start. URL paths shows directory structure, not inferred hyperlinks. Elements provides image galleries, links, headings, scripts/styles/media, and form structure.

Image previews are off until you request them. They make additional raster-image requests through the local server without cookies or referrer. Fast HTTP never executes scripts. Browser modes execute scripts and inspect same-origin frames; forms are never submitted.

Owner access

For a Vercel deployment you control, use its Protection Bypass for Automation secret. This is owner-issued authentication—not a CAPTCHA solver or an access-control exploit.

Memory only · expires after one hour · never included in profiles or crawl settings. Restarting Studio clears it. Custom firewall denies may still require a site-owner rule change.

Chromium setup

Fast HTTP needs no browser. Smart Hybrid uses HTTP results with a visible warning when Chromium is unavailable. Full Browser requires Chromium.

Source / WSL installation

npm run browser:install

Portable installation

Open Install Browser.cmd on Windows or run bash install-browser.sh in the extracted portable folder. This downloads Chromium once and uses the bundled Node runtime.

Run as a normal OS user. Chromium sandbox support is required; do not disable security protections to crawl untrusted sites.
